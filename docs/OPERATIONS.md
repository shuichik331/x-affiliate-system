# 運用ガイド

## 最初の一周

1. 「プロフィール設計」で想定読者、テーマ、発信の柱を自分の内容へ変更します。
2. 「情報収集・分析」で参考にする投稿を手入力します。本文を転載するためではなく、構成を研究するために使います。
3. ASPで案件を探して申請し、「案件管理」に候補・申請済みとして記録します。
4. ASPで承認され、専用URLが発行されたら状態を「提携承認済み」に変えます。
5. 「投稿制作」でテンプレートを作り、事実と自分の言葉で編集します。
6. 「投稿前検品」を実行し、エラーを直します。警告の各項目を人が確認して承認します。
7. テキストを書き出し、Xの投稿画面でも文字数・リンク・広告表示を確認します。
8. 投稿後、XとASPの同じ期間の累計値を「成果分析」に入力します。

## 広告表示とプラットフォーム規約

このアプリは案件付き投稿に `【PR】` を必須とします。ただし、この一語だけで表示が常に十分になるとは限りません。表示全体から広告であることが明瞭か、案件・ASPの指示と最新のルールに合うかを確認してください。

確認先（2026年9月15日確認）:

- [消費者庁 ステルスマーケティングQ&A](https://www.caa.go.jp/policies/policy/representation/fair_labeling/faq/stealth_marketing/)
- [X Automation Rules](https://help.x.com/en/rules-and-policies/x-automation)
- [X Developer Agreement](https://docs.x.com/developer-terms/agreement)
- [X Developer Policy](https://docs.x.com/developer-terms/policy)

Xはスパム、重複的な投稿、許可されない自動操作などを制限しています。将来APIを接続するときも、投稿を無条件に自動化せず、用途と最新規約を確認してください。本アプリの検品は補助で、法的判断や規約適合を保証するものではありません。

## 認証情報

`.env.example` は設定名だけを示します。実際のキーを使う段階では `.env` に保存し、GitHubへコミットしません。このMVPはキーを設定しても外部接続しません。

誤ってキーをコミットした場合は、ファイルを消すだけで済ませず、提供元でキーを無効化・再発行してください。

## バックアップと初期化

アプリを停止してから `data/workspace.sqlite3` をコピーするとバックアップできます。最初からやり直す場合は、このファイルを別の場所に退避して起動してください。新しいサンプルDBが作られます。
